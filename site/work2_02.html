TECHNICAL PROJECT / DIRECTX 12

玉転がし（DirectX 12）

C++とDirectX 12を使って、3D空間上で球体を動かすミニゲームを制作しました。完成ゲームとしての規模よりも、球体の生成、描画パイプラインの構築、リソース状態遷移やGPU同期処理を自分で理解して実装することを目的にした技術学習作品です。

開発環境

C++ / DirectX 12

制作期間

2025/10/07〜2025/12/05

制作形態

個人制作

制作背景

3Dゲームを作った経験がなかったため、まずはライブラリやエンジンに頼りすぎず、描画の流れを理解した上で簡単なゲームを作ることを目標にしました。教科書を片手にモデル描画とテクスチャ貼り付けを学び、その先の理解を深めるために、本作品では球体の生成から描画までを自分で扱っています。

使用した教科書：翔泳社『DirectX 12 3Dゲームプログラミング』

この作品で挑戦したこと

  • 球体メッシュ生成：教科書では既存モデルの描画が中心だったため、緯度・経度方向に頂点を打って球体を生成する処理を自作しました。
  • 描画パイプラインの構築：入力レイアウト、シェーダーのコンパイル、PSOの作成など、DirectX 12で描画に必要な手順を一通り組み立てました。
  • リソース状態遷移とGPU同期：Resource Barrierによるバックバッファの状態遷移と、FenceによるCPU/GPU同期を実装しました。

球体をプログラムで作成

頂点位置・法線・UV座標を生成し、三角形インデックスで接続して球体メッシュを構成しました。数学的な形状生成と、描画に必要なデータ構造のつながりを理解する目的で実装しています。

void CreateSphere(float radius, int latDiv, int lonDiv, vector<PMD_VERTEX>& outVerts, vector<unsigned short>& outIdx) {
    outVerts.clear();
    outIdx.clear();
    for (int lat = 0; lat <= latDiv; ++lat) {
        float v = (float)lat / (float)latDiv;
        float theta = v * XM_PI;
        for (int lon = 0; lon <= lonDiv; ++lon) {
            float u = (float)lon / (float)lonDiv;
            float phi = u * XM_2PI;
            float x = sinf(theta) * cosf(phi);
            float y = cosf(theta);
            float z = sinf(theta) * sinf(phi);
            PMD_VERTEX vx{};
            vx.pos = XMFLOAT3(x * radius, y * radius, z * radius);
            vx.normal = XMFLOAT3(x, y, z);
            vx.uv = XMFLOAT2(u, v);
            outVerts.push_back(vx);
        }
    }
    for (int lat = 0; lat < latDiv; ++lat) {
        for (int lon = 0; lon < lonDiv; ++lon) {
            int cur = lat * (lonDiv + 1) + lon;
            int next = (lat + 1) * (lonDiv + 1) + lon;
            outIdx.push_back((unsigned short)cur);
            outIdx.push_back((unsigned short)next);
            outIdx.push_back((unsigned short)(cur + 1));
            outIdx.push_back((unsigned short)(cur + 1));
            outIdx.push_back((unsigned short)next);
            outIdx.push_back((unsigned short)(next + 1));
        }
    }
}

グラフィックスパイプラインの構築

3Dエンジンでは隠蔽されることの多い描画の流れを理解するため、シェーダーのコンパイル、入力レイアウト、PSO作成を自分で組み立てました。DirectX 12の初期化や描画設定が、実際に画面へ出力されるまでの関係を確認できました。

ComPtr<ID3DBlob> vsBlob, psBlob;

リソースバリアと同期処理

描画前後のバックバッファ状態を切り替える処理と、GPUがコマンドを処理し終えるまでCPU側で待機する同期を実装しました。ゲームエンジンでは見えにくい低レベルの制御を体験できた点が、この作品の学習成果です。

auto barrier = CD3DX12_RESOURCE_BARRIER::Transition(
    g_backBuffers[bbIdx],
    D3D12_RESOURCE_STATE_PRESENT,
    D3D12_RESOURCE_STATE_RENDER_TARGET);
g_cmdList->ResourceBarrier(1, &barrier);

/* Clear や Draw などを実行 */

barrier = CD3DX12_RESOURCE_BARRIER::Transition(
    g_backBuffers[bbIdx],
    D3D12_RESOURCE_STATE_RENDER_TARGET,
    D3D12_RESOURCE_STATE_PRESENT);
g_cmdList->ResourceBarrier(1, &barrier);

g_cmdQueue->Signal(g_fence, g_fenceVal);
if (g_fence->GetCompletedValue() != g_fenceVal) {
    HANDLE ev = CreateEvent(nullptr, FALSE, FALSE, nullptr);
    g_fence->SetEventOnCompletion(g_fenceVal, ev);
    WaitForSingleObject(ev, INFINITE);
    CloseHandle(ev);
}
g_cmdAlloc->Reset();

学んだこと

球体メッシュの頂点生成、描画パイプライン、リソース状態遷移、GPU同期処理を一連の流れとして実装することで、3Dゲームエンジンが普段隠している描画処理の基礎を学びました。単に「3Dが表示できた」だけでなく、どの段階で何を設定しているのかを理解しながら実装できたことが、この作品の価値です。
